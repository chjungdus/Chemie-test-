🔬 Eigenschaften von Säuren

Allgemeine Eigenschaften saurer Lösungen

  • Saurer Geschmack – z.B. Essig, Zitronensaft (niemals unbekannte Säuren probieren!)
  • Elektrische Leitfähigkeit – Säuren sind Elektrolyte, sie leiten Strom in wässriger Lösung
  • Indikatorwirkung – Lackmus wird rot, Universalindikator zeigt rot/orange
  • pH-Wert < 7 – je kleiner der pH-Wert, desto stärker die Säure
  • Reaktion mit unedlen Metallen – es entsteht Wasserstoffgas (H₂) und ein Salz
  • Neutralisation mit Laugen/Basen – Säure + Base → Salz + Wasser
  • Korrosiv/ätzend – konzentrierte Säuren zerstören Haut und Materialien
  • Protonengeber – Säuren geben in Wasser H⁺-Ionen (Protonen) ab → Oxoniumionen entstehen

⚗️ Reaktionsgleichungen: Säure + Wasser

📌 Das Grundprinzip

Wenn eine Säure in Wasser gelöst wird, gibt sie ein Proton (H⁺) an ein Wassermolekül ab. Das Wassermolekül nimmt das Proton auf und wird zum Oxoniumion (H₃O⁺).

HA + H₂O ⇌ H₃O⁺ + A⁻

HA = beliebige Säure | A⁻ = Säurerestanion

Beispiele der 8 Säuren

Chlorwasserstoff (HCl) in Wasser
HCl + H₂O → H₃O⁺ + Cl⁻

HCl gibt sein Proton vollständig ab → starke Säure, vollständige Dissoziation

Schwefelsäure (H₂SO₄) in Wasser
H₂SO₄ + 2 H₂O → 2 H₃O⁺ + SO₄²⁻

Zweiprotonige Säure – gibt 2 Protonen ab

Salpetersäure (HNO₃) in Wasser
HNO₃ + H₂O → H₃O⁺ + NO₃⁻

Starke Säure, vollständige Dissoziation

Essigsäure (CH₃COOH) in Wasser
CH₃COOH + H₂O ⇌ H₃O⁺ + CH₃COO⁻

Schwache Säure – nur teilweise Dissoziation (Gleichgewichtspfeil!)

Ameisensäure (HCOOH) in Wasser
HCOOH + H₂O ⇌ H₃O⁺ + HCOO⁻

Schwache Säure

Kohlensäure (H₂CO₃) in Wasser
H₂CO₃ + H₂O ⇌ H₃O⁺ + HCO₃⁻

Erste Stufe → Hydrogencarbonat | Zweite Stufe: HCO₃⁻ + H₂O ⇌ H₃O⁺ + CO₃²⁻

Phosphorsäure (H₃PO₄) in Wasser
H₃PO₄ + H₂O ⇌ H₃O⁺ + H₂PO₄⁻

Dreiprotonige Säure – gibt bis zu 3 Protonen ab

Citronensäure (C₆H₈O₇) in Wasser
C₆H₈O₇ + H₂O ⇌ H₃O⁺ + C₆H₇O₇⁻

Dreiprotonige schwache Säure

⚡ Bildung von Oxoniumionen

Was ist ein Oxoniumion?

Das Oxoniumion (H₃O⁺) entsteht, wenn ein Wassermolekül ein Proton (H⁺) von einer Säure aufnimmt. Es ist die eigentliche Ursache für saure Eigenschaften in wässriger Lösung.

H₂O + H⁺ → H₃O⁺

Schritt-für-Schritt Erklärung

Schritt 1 – Die Säure dissoziiert

Die Säure HA zerfällt in Wasser in ein Proton (H⁺) und ein Säurerestanion (A⁻).

HA → H⁺ + A⁻
Schritt 2 – Proton wird vom Wasser aufgenommen

Das freigesetzte Proton H⁺ bindet sich sofort an ein Wassermolekül H₂O. Das freie Elektronenpaar des Sauerstoffs im Wasser zieht das Proton an.

H₂O + H⁺ → H₃O⁺
Schritt 3 – Gesamtreaktion

Zusammengefasst schreibt man die Reaktion als Protonenübertragung von der Säure auf das Wasser:

HA + H₂O → H₃O⁺ + A⁻

HA = Säure (Protonendonator)   H₂O = Base (Protonenakzeptor)

Beispiel: HCl in Wasser
HCl + H₂O → H₃O⁺ + Cl⁻

HCl gibt sein Proton an H₂O ab → Chloridion Cl⁻ und Oxoniumion H₃O⁺ entstehen

🔵 Oxoniumion H₃O⁺

= 1 Sauerstoffatom + 3 Wasserstoffatome + positive Ladung

Früher auch Hydroniumion genannt

Verantwortlich für den sauren pH-Wert

⚡ Protonentheorie (Brønsted)

Säure = Protonendonator (gibt H⁺ ab)

Base = Protonenakzeptor (nimmt H⁺ auf)

Wasser wirkt als Base!

📊 Je mehr H₃O⁺ ...

... desto niedriger der pH-Wert

... desto stärker die Säure

Bei pH 7: gleich viel H₃O⁺ und OH⁻
